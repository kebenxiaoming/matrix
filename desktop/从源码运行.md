# 从源码运行桌面客户端

仓库里**不包含** `视频矩阵分发.exe`（`dist/` 在 `.gitignore` 里），exe 是本地打包产物。
拉下代码后按下面步骤直接跑源码；要 exe 就自己执行第五步打包一次。

## 一、前置条件

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| Python | 3.11 及以上（本项目实测 3.13.14） |
| 浏览器 | 建议装 Google Chrome。发布优先调用系统 Chrome，视频号必须用它（内置 Chromium 缺 h264 会转码失败） |
| 网络 | 首次装依赖需要联网 |

## 二、安装依赖

在**项目根目录**执行（不是 `desktop/` 里）：

```bat
:: 1. 建虚拟环境
python -m venv .venv-desktop

:: 2. 激活
.venv-desktop\Scripts\activate

:: 3. 装客户端依赖（不要用根目录的 requirements.txt）
pip install -r requirements-desktop.txt

:: 4. 装 Playwright 的 Chromium（登录扫码和兜底发布要用）
python -m playwright install chromium
```

> 根目录的 `requirements.txt` 是原命令行版本（MySQL / Redis / eventlet）的依赖，
> 桌面客户端用不到，装了反而可能失败。客户端依赖统一看 `requirements-desktop.txt`。

## 三、运行

```bat
python -m desktop.main
```

必须**在项目根目录**执行，`desktop` 是一个包，`python desktop\main.py` 也能起，
但 `-m` 方式能保证根目录下的 `douyin_uploader`、`utils` 等模块正常导入。

启动后是正常的图形界面，四个平台账号需要各自扫码登录一次（详见 `客户端使用说明.md`）。

## 四、先自检（可选，排查环境问题很有用）

```bat
python -m desktop.main --selftest
```

会依次检查 Playwright 浏览器、各平台上传器模块、SQLite、小红书签名器，
最后一行输出 `RESULT = PASS` 即环境可用。结果同时写到 `data/logs/selftest.log`。

其他调试参数：

```bat
python -m desktop.main --screenshot out.png          :: 截图界面后退出
python -m desktop.main --screenshot out.png --page queue   :: 截指定页面
```

## 五、打包成 exe

```bat
python desktop\build\build_all.py
```

产物：`dist\视频矩阵分发\视频矩阵分发.exe`

- 构建脚本用**当前解释器**（即激活的 `.venv-desktop`）调用 PyInstaller，所以务必先激活虚拟环境
- 会自动生成图标、复制 Playwright 浏览器进包、把旧的 `data` 目录（账号 cookie）保留下来
- 上一次的成品会归档为 `dist_old_HHMMSS`，确认新版可用后可手动删除
- 打包耗时约 2～4 分钟，成品约 665MB（含 Chromium）

## 六、数据目录

| 运行方式 | 数据位置 |
| --- | --- |
| 源码运行 | `项目根\data` |
| 打包运行 | `exe 同级\data` |

两套数据是**独立的**：源码里登录的账号不会出现在 exe 版本里，反之亦然。
需要共用时用环境变量指定同一个目录：

```bat
set MATRIX_DATA_DIR=D:\matrix-data
python -m desktop.main
```

`data` 目录内容：`matrix.db`（SQLite 主库）、`accounts/`（各平台 cookie）、`config.json`、`logs/`。

## 七、常用环境变量

| 变量 | 作用 |
| --- | --- |
| `MATRIX_DATA_DIR` | 指定数据目录（源码/打包共用一套数据时用） |
| `MATRIX_HEADLESS=0` | 发布时显示浏览器窗口（默认无头，排查发布问题用） |
| `MATRIX_DRY_RUN=1` | 只填表不点发布（调试用） |
| `MATRIX_TENCENT_CHANNEL` | 指定视频号用的 Chrome 路径，设为 `none` 强制用内置 Chromium |

## 八、常见问题

**Q：`ModuleNotFoundError: No module named 'desktop'`**
不在项目根目录执行。`cd` 到含 `desktop/`、`douyin_uploader/` 的那一层再运行。

**Q：`ModuleNotFoundError: No module named 'PySide6'`**
虚拟环境没激活，或装错了依赖文件。确认命令提示符前有 `(.venv-desktop)`，然后
`pip install -r requirements-desktop.txt`。

**Q：启动报 Playwright 找不到浏览器**
执行 `python -m playwright install chromium`。若只想用系统 Chrome，装 Chrome 也能发布，
但登录扫码流程仍依赖 Playwright 浏览器实例。

**Q：界面能开，但发布时提示找不到 Chrome**
装 Google Chrome，或用 `MATRIX_TENCENT_CHANNEL` 指定路径。视频号尤其依赖 Chrome。

**Q：`git pull` 后 `desktop` 目录不存在**
客户端的代码不在上游仓库里（`desktop/` 需自行提交推送），
只在本地存在时别人拉是看不到的。
